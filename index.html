What's included

Everything auth needs, already built

🛡️

RoleMiddleware

role:admin, role:staff,admin — protect any route with any role combination.

🔐

OTP Password Reset

Email OTP — no insecure link tokens that expire. 3-step flow: send → verify → reset.

🔄

Force Password Change

Set must_change_password=true on any user. Middleware handles the redirect with infinite-loop protection.

👤

StaffInfo Model

Extended employee profile: employee ID, job title, employment status, gender, emergency contact, office location.

⏱️

Auto-Timestamps

Tracks last_login_at and last_password_change_at automatically on every auth event.

🌱

Admin Seeder

One command — php artisan db:seed --class=AdminUserSeeder — and your default admin is ready.

🗑️

Soft Deletes

Users are never hard-deleted. Restore any account without data loss.

📋

6 Form Requests

Login, Register, ForcePasswordChange, SendOtp, VerifyOtp, ResetPasswordOtp — all validated.

📦

Drop-in Ready

Copy src/ into your app, migrate, seed, register middleware — done. No Composer package needed.
